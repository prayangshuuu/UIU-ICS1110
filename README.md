## About

This repository contains solutions to the programming problems from the **ICS 1110 – Structured Programming** course at **United International University (UIU)**.

The solutions are written in **C** and organized according to the official problem sheets used throughout the course. Every problem includes:

- 📄 Original problem statement
- 📥 Sample input
- 📤 Sample output
- 💻 C solution
- 📖 Short explanation
- ⏱️ Time & Space complexity

The goal of this repository is to serve as a learning resource for students studying Structured Programming.

## Getting Started

Clone the repository.

```bash
git clone https://github.com/prayangshuuu/UIU-ICS1110.git
cd UIU-ICS1110
```

Compile any solution using GCC.

```bash
gcc solution.c -o solution
./solution
```
